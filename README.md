# Ray Nguyen — Marketing & Customer Experience

A chronological career portfolio covering Mobile Mart, Barclay Pearce Capital, Mobo Group and Bami. The approved design uses a continuous midnight-blue background, large typography, real team photographs and scroll-driven 3D perspective.

## Edit and preview

Edit index.html, styles.css and main.js. No dependencies are required. Run:

```sh
node scripts/serve.mjs
node scripts/build.mjs
```

The server opens at http://127.0.0.1:4173. Stop another preview using that port first. The build embeds the font, photographs, CSS and JavaScript into publish/index.html. Upload that file as index.html at the repository root. Keep Ray-Nguyen-Resume.pdf alongside it. The updated editable source is maintained locally. The existing source ZIP in this repository belongs to the previous design.

## Content and media

Career responsibilities and historical metrics are drawn from Ray’s supplied résumé and additional notes. The CV is the original PDF and remains available at https://ray-nguyen.github.io/Ray-Nguyen-Resume.pdf.

Portrait and four team photographs supplied by Ray. Bami restaurant and app promotion imagery are drawn from https://bamivietnamese.com.au/ and credited in the page. Company imagery provides context and is not attributed to Ray as original artwork. The Mobile Mart customer journey is an illustration, not a project screenshot. Inter is bundled with its licence.

The motion control pauses scroll effects. Reduced-motion preferences disable animation by default. Content remains readable without JavaScript. Contact links open email and LinkedIn; the résumé can be viewed or downloaded.

Published at https://ray-nguyen.github.io/ through GitHub Pages, master branch, repository root.
