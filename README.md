# Ray Nguyen — A few chapters of my story

A chronological portfolio that moves from study in Vietnam and Wollongong through Mobile Mart, Barclay Pearce Capital, Mobo Group and Bami Vietnamese.

Short first-person summaries replace the resume transcription. The existing portrait introduces Ray; layered study notes, selected results and a restaurant receipt-style career snapshot move at different speeds as visitors scroll. These are designed summaries of CV facts, not reproductions of original campaign materials.

The site uses native scrolling, sticky desktop chapters and a year navigation. Phone layouts follow the same story in a single column with gentler parallax. Reduced-motion preferences and the footer pause control disable parallax. Content and navigation remain available without JavaScript.

## Editing

Extract ray-nguyen-portfolio-source.zip. Edit index.html, styles.css and main.js. No dependencies need to be installed.

    node scripts/serve.mjs
    node scripts/build-standalone.mjs
